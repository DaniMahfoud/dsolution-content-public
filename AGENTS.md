# Public content repository instructions

- Store only public captions, schedules, and Instagram-ready image assets.
- Never add Instagram tokens, API keys, customer data, or private history.
- Use unique lowercase post IDs.
- Keep new posts as `draft` until the owner explicitly confirms the copy,
  image, schedule, and public URL.
- Only explicitly confirmed posts may be changed to `ready`; `ready` entries
  are eligible for unattended Instagram publishing.
- Prefer PNG/JPEG assets at 1080x1350 and stable raw GitHub HTTPS URLs.
